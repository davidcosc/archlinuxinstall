## dwl

- git clone https://codeberg.org/dwl/dwl.git
- curl -O https://archive.archlinux.org/packages/w/wlroots0.19/wlroots0.19-0.19.3-1-x86_64.pkg.tar.zst
- curl -O https://archive.archlinux.org/packages/w/wlroots0.19/wlroots0.19-0.19.3-1-x86_64.pkg.tar.zst.sig
- pacman-key --verify wlroots0.19-0.19.3-1-x86_64.pkg.tar.zst.sig wlroots0.19-0.19.3-1-x86_64.pkg.tar.zst
- pacman -U wlroots0.19-0.19.3-1-x86_64.pkg.tar.zst
